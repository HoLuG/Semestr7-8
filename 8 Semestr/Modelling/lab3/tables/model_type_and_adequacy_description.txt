ЛОГИЧЕСКАЯ МОДЕЛЬ (тип, формализация и проверка адекватности)
============================================================

1) ТИП ПОСТРОЕННОЙ МОДЕЛИ
------------------------

В работе фактически используются две взаимосвязанные модели:

  1. Стохастическая вычислительная модель (без учителя):
     - кластеризация k-means при k=2 в пространстве композитных признаков (G1..Gm);
     - результатом являются метки классов y ∈ {0,1} и центры кластеров.

  2. Логическая интерпретационная модель (детерминированная):
     - на основе меток y (полученных k-means) строится логическая функция f_logic
       в виде СДНФ по бинаризованным признакам;
     - далее СДНФ минимизируется (метод Куайна–МакКласки), получаем минимизированную ДНФ.

Таким образом, итог — это композиция:
  исходные данные → (k-means даёт y) → (логическая аппроксимация y по бинарным признакам).


2) ФОРМАЛИЗАЦИЯ (по стилю отчёта)
--------------------------------

Пусть задана выборка объектов:
  X = { x^(k) }_{k=1..n},  x^(k) = (x_1^(k), ..., x_p^(k)),
где p — число исходных числовых признаков из diabetes.csv.

2.1. Бинаризация исходных признаков для вычисления взаимосвязей
  Для каждого признака x_i задаётся порог t_i:
    t_i = median(x_i)   (устойчивый порог, снижает влияние выбросов).
  Определяем бинарные события:
    A_i(x) = [ x_i <= t_i ] ∈ {0,1}.

2.2. Оценка взаимосвязей между признаками
  Для каждой пары (i,j) строится таблица сопряжённости 2×2 по (A_i, A_j)
  и вычисляется один из коэффициентов взаимосвязи S_ij, например:
    K_ij (lift), φ_ij (Пирсон), Q_ij (Юл), Y_ij (Юл).
  В отчёте рассматривается выбор среди:
    S_ij ∈ { max(K_ij,K_ji), |φ_ij|, |Q_ij|, |Y_ij| }.

2.3. Сокращение размерности (композитные признаки)
  По выбранной мере S_ij и порогу S_thr строится граф зависимостей:
    вершины — признаки, ребро (i,j) проводится, если S_ij >= S_thr.
  По графу выделяются компоненты связности (группы зависимых признаков).
  Для каждой группы формируется композитный показатель как среднее
  от стандартизованных признаков группы:
    z_i = (x_i - μ_i) / σ_i,
    G_r = mean_{i ∈ group(r)} z_i,   r = 1..m.

2.4. Кластеризация k-means (k=2) в пространстве (G1..Gm)
  Переходим к представлению объектов:
    g^(k) = (G_1^(k), ..., G_m^(k)).
  Выполняем k-means при k=2 по евклидовой метрике:
    - назначение точек ближайшему центру;
    - пересчёт центров как среднее по точкам кластера;
    - повтор до стабилизации.
  Результат:
    y^(k) ∈ {0,1} — метка кластера для объекта k.

2.5. Логическая модель (СДНФ + минимизация)
  Для построения логической функции берём бинаризацию уже выбранных признаков
  (в текущей реализации — бинаризация композитов G_r):
    b_r(x) = [ G_r <= θ_r ] ∈ {0,1},
  где θ_r — порог (в варианте «как lab3_4.py» используется среднее по выборке).

  Логическая функция строится как дизъюнкция минтермов (СДНФ) по тем бинарным векторам,
  которые встречаются среди обучающих объектов положительного класса (Cluster=1):
    f_SDNF(b) = OR_{b ∈ M+} AND_{r=1..m} ( b_r  или  ¬b_r ),
  где M+ — множество уникальных бинарных строк в положительном классе на обучающей части.

  Затем применяется минимизация (Куайн–МакКласки), получаем ДНФ:
    f_min(b) = OR_{t ∈ T} AND_{r∈S(t)} literal_{t,r},
  где T — набор импликант (в каждом месте может быть «не важно»).


3) ПРОВЕРКА АДЕКВАТНОСТИ (без конкретики, сравнение с данными отчёта)
--------------------------------------------------------------------

Под «адекватностью» здесь понимается согласованность:
  (а) разбиений/предсказаний с исходными данными и методикой;
  (б) результатов с теми значениями, которые приведены в lab3_report.tex.

3.1. Контроль корректности разбиения (рабочая/контрольная)
  Разбиение выполняется 50/50 по методике:
    вариационный ряд по Glucose + чередование.

  Для подтверждения, что две половины «одинаковы по распределению»,
  применяется двухвыборочный критерий Колмогорова–Смирнова (α=0.05)
  для каждого используемого непрерывного признака (в логике — для G1..Gm):
    D_n = sup_x |F_work(x) - F_ctrl(x)|,
    D_crit = 1.36 * sqrt((n1+n2)/(n1*n2)).
  Требование:
    D_n <= D_crit  (распределения не различаются статистически значимо).

3.2. Адекватность логической интерпретации (внутренняя согласованность)
  Логическая модель строится как аппроксимация меток k-means, поэтому проверяется:
    Acc_train = mean( f_min(b_work) == y_work ),
    Acc_test  = mean( f_min(b_ctrl) == y_ctrl ),
  а также матрица ошибок на контрольной части:
    TP, FN, FP, TN.
  Интерпретация:
    высокая точность означает, что логическая ДНФ действительно описывает правило,
    близкое к полученному разбиению k-means (то есть даёт интерпретацию кластеров).

3.3. Сопоставление с данными из отчёта (lab3_report.tex)
  В отчёте зафиксированы ориентиры для внешней контрольной оценки по Outcome:
    - выбранный итоговый вариант по максимуму macro-F1:
        m=4, S_ij=|Y_ij|, S_thr=0.25, F1_macro=0.7261, BalAcc=0.7298;
    - вариант, выбранный по внутреннему score:
        m=2, S_ij=|Y_ij|, S_thr=0.20, F1_macro=0.5842, BalAcc=0.5831.

  Для проверки адекватности нужно сравнить результаты вашего запуска с отчётом:
    - выбранные (m, S_ij, S_thr) и состав групп (табл. reduction_groups.tex);
    - размеры кластеров и центры (табл. cluster_sizes.tex, cluster_centers.tex);
    - внешние контрольные метрики по Outcome (табл. accuracy.tex),
      используя «лучшее сопоставление меток кластеров и Outcome».

  Критерий «адекватности по отчёту» формулируется так:
    - при одинаковых настройках (m и группировка) показатели должны быть близки
      к значениям, приведённым в отчёте (допускаются небольшие расхождения из-за
      инициализации k-means и иных деталей реализации);
    - качественные выводы должны совпадать: вариант m=4 согласуется с Outcome лучше,
      чем вариант m=2 (в терминах macro-F1 и BalAcc), как указано в выводах отчёта.
