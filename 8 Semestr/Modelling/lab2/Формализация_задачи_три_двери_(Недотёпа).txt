Формализация эпизода «три двери» (вариант задачи Монти Холла)
Источник условий: фрагмент из «Лукьяненко — Недотёпа» (козы / колесо от кареты; барон открывает одну из НЕ выбранных дверей с козой; игрок может сменить выбор).

1) Объекты и обозначения
Пусть есть множество дверей D = {1, 2, 3}.
За одной дверью находится приз R (в тексте: колесо от кареты), за двумя — козы G.

Случайное размещение:
W ∈ D — «выигрышная» дверь (с колесом).
Предположение (честная игра): Pr(W = i) = 1/3 для i ∈ D.
Тогда за дверью i находится:
  - колесо, если i = W,
  - коза, если i ≠ W.

Действия игрока:
X ∈ D — первоначальный выбор игрока.
S ∈ {stay, switch} — стратегия после открытия двери бароном:
  - stay: оставить X
  - switch: сменить на оставшуюся закрытую дверь

Действия ведущего (барона):
После выбора X ведущий открывает одну дверь O ∈ D \ {X}, такую что O ≠ W (т.е. за O гарантированно коза).
Если D \ {X} содержит две «козьи» двери, ведущий выбирает, какую открыть, произвольно (например, равновероятно); на вероятность выигрыша игрока при стратегии switch это не влияет.

После открытия O остаются две закрытые двери: X и Y, где
Y = единственная дверь из D \ {X, O}.
Если игрок выбирает switch, то его финальный выбор Y; если stay — финальный выбор X.

2) Пространство элементарных исходов
Элементарный исход ω можно задать тройкой (W, X, O), где:
  - W ∈ {1,2,3}
  - X ∈ {1,2,3}
  - O ∈ {1,2,3} \ {X} и O ≠ W

Распределение:
  - W равномерно по D
  - X задаётся игроком (если «наугад», то можно моделировать как равномерный выбор: Pr(X=i)=1/3)
  - O выбирается ведущим по правилу «открыть козу, не выбранную игроком»

3) События выигрыша
Выигрыш при стратегии stay:
  Win_stay ⇔ X = W
Т.е. игрок выигрывает только если изначально выбрал выигрышную дверь.

Выигрыш при стратегии switch:
  Win_switch ⇔ Y = W ⇔ X ≠ W
Обоснование: ведущий никогда не открывает W, поэтому после открытия козьей двери единственная оставшаяся «альтернатива» Y будет выигрышной тогда и только тогда, когда исходный выбор X был неверным.

4) Вероятности (классический результат)
Если X выбирается наугад (равномерно):
  Pr(Win_stay)   = Pr(X = W)   = 1/3
  Pr(Win_switch) = Pr(X ≠ W)   = 2/3

То есть оптимальная стратегия — всегда switch (в тексте Трикс: «меняем»), она даёт выигрыш с вероятностью 2/3 в каждом независимом испытании.

5) Табличная форма (коротко)
Случай A: X = W (вероятность 1/3)
  - ведущий открывает любую козу из двух
  - stay → выигрыш
  - switch → проигрыш

Случай B: X ≠ W (вероятность 2/3)
  - среди двух невыбранных дверей одна — W, другая — коза
  - ведущий обязан открыть именно козу
  - stay → проигрыш
  - switch → выигрыш

6) Серия испытаний (много повторов)
Пусть проводится n независимых игр при одинаковых правилах.
При стратегии «всегда switch» каждая игра — бернуллиевская с параметром p = 2/3.
Тогда число выигрышей K ~ Bin(n, 2/3).
Математическое ожидание: E[K] = n * (2/3).
Дисперсия: Var[K] = n * (2/3) * (1/3) = 2n/9.

Для примера из текста (n = 100):
  E[K] = 66.666...
  Наблюдение: K = 67 (колёс), что близко к ожиданию, и не является «чудом» (это типичный результат для p=2/3).

7) Уточнение, почему рассуждение «после открытия шанс 1/2» неверно
Ключ: открытие двери ведущим НЕ является «случайным независимым раскрытием», а зависит от X и от W (ведущий всегда показывает козу и избегает W).
Поэтому условное распределение W при наблюдении (X, O) меняется не так, как при «случайном открытии».
Интуитивно: вероятность 1/3 того, что X правильный, остаётся за X; оставшиеся 2/3 «переносятся» на единственную оставшуюся закрытую дверь Y.

8) Формализация в терминах условной вероятности (кратко)
Фиксируем X = x. Ведущий открывает O = o, где o ≠ x и o ≠ W.
Тогда:
  Pr(W = x | O = o, X = x) = 1/3
  Pr(W = y | O = o, X = x) = 2/3
где y — третья дверь (не x и не o).
Следовательно, switch выигрывает с вероятностью 2/3.

9) Минимальный алгоритм симуляции (если нужно моделирование)
Повторить n раз:
  1) W ← случайно из {1,2,3}
  2) X ← случайно из {1,2,3} (или заданная политика)
  3) O ← выбрать из {1,2,3}\{X} такую дверь, что O ≠ W (если две — выбрать любую)
  4) Y ← единственная дверь из {1,2,3}\{X,O}
  5) Если стратегия = switch: выбор = Y иначе выбор = X
  6) Выигрыш, если выбор = W

Готово: это строгая формализация условий эпизода и математического результата (p=2/3 при «всегда менять»).
