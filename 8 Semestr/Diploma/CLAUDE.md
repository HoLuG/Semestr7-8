## Описание проекта
Сделать реализацию базисного подмножества Рефала-5,использующую
раскрученные (bootstrapped) очереди для представления объектных выражений.
Раскрученная структура данных — обобщённый контейнер C<T>, имеющий две реализации:
• мелкий контейнер, ограниченный по ёмкости Shallow<T>,
• глубокий контейнер — контейнер мелких контейнеров C<Shallow<T>>.
