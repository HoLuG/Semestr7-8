# Подробное объяснение алгоритма SVD на примере

## Исходная матрица A

В нашем примере используется матрица размером **5×3**:

```
A = [
  [8.02,  6.04,  4.58],
  [8.76,  5.32,  1.84],
  [5.01,  8.95,  5.16],
  [9.45,  8.26,  7.09],
  [1.30,  5.08,  9.43]
]
```

**Размеры:** m = 5 строк, n = 3 столбца

---

## Шаг 1: Транспонирование матрицы A

Транспонируем A, чтобы получить A^T размером **3×5**:

```
A^T = [
  [8.02,  8.76,  5.01,  9.45,  1.30],
  [6.04,  5.32,  8.95,  8.26,  5.08],
  [4.58,  1.84,  5.16,  7.09,  9.43]
]
```

**Код:** `val At = transpose(AArray)` (строки 377, 436-441)

---

## Шаг 2: Вычисление симметричной матрицы B = A^T · A

Умножаем A^T (3×5) на A (5×3), получаем симметричную матрицу **B размером 3×3**:

```
B = A^T · A = [
  [b₁₁, b₁₂, b₁₃],
  [b₂₁, b₂₂, b₂₃],
  [b₃₁, b₃₂, b₃₃]
]
```

**Формула:** `bᵢⱼ = Σₖ (A^T[i][k] · A[k][j])` для k от 0 до 4

**Пример вычисления:**
- `b₁₁ = 8.02² + 8.76² + 5.01² + 9.45² + 1.30² = 64.32 + 76.74 + 25.10 + 89.30 + 1.69 = 257.15`
- `b₁₂ = 8.02·6.04 + 8.76·5.32 + 5.01·8.95 + 9.45·8.26 + 1.30·5.08 = ...`
- И так далее для всех элементов

**Код:** `val B = multiply(At, AArray)` (строки 379, 444-456)

**Важно:** B — симметричная матрица (B = B^T), поэтому все её собственные значения вещественные и неотрицательные.

---

## Шаг 3: Метод Крылова для нахождения собственных значений и векторов B

### 3.1. Построение последовательности Крылова

**Начальный вектор:** `y[0] = [1.0, 1.0, 1.0]` (все единицы)

**Последовательность Крылова:**
- `y[1] = B · y[0]` (умножение матрицы B на вектор y[0])
- `y[2] = B · y[1] = B² · y[0]`
- `y[3] = B · y[2] = B³ · y[0]`

**Пример вычисления y[1]:**
```
y[1][0] = B[0][0]·1.0 + B[0][1]·1.0 + B[0][2]·1.0
y[1][1] = B[1][0]·1.0 + B[1][1]·1.0 + B[1][2]·1.0
y[1][2] = B[2][0]·1.0 + B[2][1]·1.0 + B[2][2]·1.0
```

**Код:** строки 125-129 в `krylovMethod()`:
```kotlin
val y = Array(n + 1) { DoubleArray(n) }
for (i in 0 until n) y[0][i] = 1.0
for (i in 1..n) {
    y[i] = multiplyMatrixVector(A, y[i - 1], n)
}
```

**Результат:** массив `y` размером (n+1) × n = 4 × 3:
- `y[0]` = начальный вектор [1, 1, 1]
- `y[1]` = B · y[0]
- `y[2]` = B² · y[0]
- `y[3]` = B³ · y[0]

---

### 3.2. Построение системы для коэффициентов характеристического многочлена

**Цель:** найти коэффициенты p₀, p₁, p₂ характеристического многочлена:
```
p(λ) = λ³ + p₂·λ² + p₁·λ + p₀
```

**Теорема Крылова:** Если `y[0], y[1], ..., y[n-1]` линейно независимы, то:
```
[y[n-1]ᵀ]     [p₀]
[y[n-2]ᵀ]  ·  [p₁]  =  y[n]
[y[0]ᵀ]       [p₂]
```

**В нашем случае (n=3):**
```
[y[2]ᵀ]     [p₀]
[y[1]ᵀ]  ·  [p₁]  =  y[3]
[y[0]ᵀ]     [p₂]
```

**Код:** строки 133-141:
```kotlin
// Формируем матрицу системы: строки = y[2], y[1], y[0] (в обратном порядке)
val AMatrixTemp = Array(n) { row ->
    DoubleArray(n) { j -> y[(n - 1) - row][j] }
}
// Транспонируем (столбцы становятся строками)
val AMatrix = Array(n) { i ->
    DoubleArray(n) { j -> AMatrixTemp[j][i] }
}
val f = y[n].clone()  // правая часть = y[3]
```

**Пример структуры системы:**
```
AMatrix = [
  [y[2][0], y[1][0], y[0][0]],
  [y[2][1], y[1][1], y[0][1]],
  [y[2][2], y[1][2], y[0][2]]
]

f = [y[3][0], y[3][1], y[3][2]]
```

---

### 3.3. Решение системы методом Гаусса

Решаем систему `AMatrix · resP = f` методом Гаусса с выбором главного элемента.

**Код:** `solveLinearSystem()` (строки 300-340)

**Результат:** вектор `resP = [p₀, p₁, p₂]` (коэффициенты характеристического многочлена)

---

### 3.4. Построение характеристического многочлена

**Формула:** `p(λ) = λ³ + p₂·λ² + p₁·λ + p₀`

**Хранение в коде:** массив `polyDesc = [a₃, a₂, a₁, a₀]`, где:
- `a₃ = 1.0` (коэффициент при λ³)
- `a₂ = -resP[2]` (коэффициент при λ²)
- `a₁ = -resP[1]` (коэффициент при λ)
- `a₀ = -resP[0]` (свободный член)

**Код:** строки 148-150:
```kotlin
val polyDesc = DoubleArray(n + 1)
polyDesc[0] = 1.0
for (i in 0 until n) polyDesc[i + 1] = -resP[i]
```

**Пример:** Если `resP = [10.5, -5.2, 2.1]`, то:
```
polyDesc = [1.0, -2.1, 5.2, -10.5]
p(λ) = 1.0·λ³ - 2.1·λ² + 5.2·λ - 10.5
```

---

### 3.5. Поиск корней характеристического многочлена (собственных значений)

**Метод:** бисекция + сканирование с адаптивным шагом

**Алгоритм:**
1. **Оценка границ:** по теореме Коши: `bound = 1 + max(|a₂|, |a₁|, |a₀|) / |a₃|`
2. **Сканирование:** ищем интервалы `[left, right]`, где `p(left) · p(right) < 0` (смена знака)
3. **Бисекция:** на каждом интервале уточняем корень методом бисекции до точности `eps = 1e-7`
4. **Повтор:** делаем 4 прохода с уменьшающимся шагом, пока не найдём все n корней

**Код:** `findPolynomialRoots()` (строки 159-239)

**Результат:** массив `eigenValues = [λ₀, λ₁, λ₂]` (собственные значения B)

**Важно:** Для симметричной матрицы B все собственные значения вещественные и неотрицательные.

**Пример:** Если `eigenValues = [250.5, 15.2, 0.8]`, это означает, что матрица B имеет собственные значения 250.5, 15.2 и 0.8.

---

### 3.6. Вычисление собственных векторов методом Крылова

Для каждого собственного значения `λᵢ` находим соответствующий собственный вектор `vᵢ`.

**Формула Крылова:**
```
vᵢ = y[n-1] + q₂·y[n-2] + q₃·y[n-3] + ... + qₙ·y[0]
```

где коэффициенты `qⱼ` вычисляются рекуррентно:
- `q₁ = 1.0`
- `qⱼ = λᵢ · qⱼ₋₁ + poly[j-1]` для j = 2..n

**В нашем случае (n=3):**
```
vᵢ = y[2] + q₂·y[1] + q₃·y[0]
```

где:
- `q₁ = 1.0`
- `q₂ = λᵢ · q₁ + poly[1] = λᵢ · 1.0 + a₂`
- `q₃ = λᵢ · q₂ + poly[2] = λᵢ · q₂ + a₁`

**Код:** `findEigenvectorsKrylov()` (строки 250-288):
```kotlin
val x = y[n - 1].clone()  // x = y[2]
val q = mutableListOf(1.0)
for (j in 2..n) {
    val qJ = lambda * q[j - 2] + poly[j - 1]
    q.add(qJ)
    val yIndex = n - j  // y[2], y[1], y[0]
    for (k in 0 until n) x[k] += qJ * y[yIndex][k]
}
```

**Нормализация:** После вычисления нормализуем вектор:
```
vᵢ_normalized = vᵢ / ||vᵢ||
```

где `||vᵢ|| = sqrt(vᵢ[0]² + vᵢ[1]² + vᵢ[2]²)`

**Результат:** массив `Vfull` размером n × n = 3 × 3, где:
- `Vfull[i]` = i-й собственный вектор (хранится как **строка**)

**Пример:**
```
Vfull = [
  [v₀[0], v₀[1], v₀[2]],  // собственный вектор для λ₀
  [v₁[0], v₁[1], v₁[2]],  // собственный вектор для λ₁
  [v₂[0], v₂[1], v₂[2]]   // собственный вектор для λ₂
]
```

## Шаг 4: Сортировка собственных значений по убыванию

Сортируем собственные значения и соответствующие собственные векторы по убыванию.

**Код:** строки 388-389:
```kotlin
val idxB = eigValsB.indices.sortedByDescending { eigValsB[it] }.toIntArray()
val lambdaSortedB = DoubleArray(n) { eigValsB[idxB[it]] }
```

**Пример:** Если `eigValsB = [15.2, 250.5, 0.8]`, то:
- `idxB = [1, 0, 2]` (индексы в порядке убывания значений)
- `lambdaSortedB = [250.5, 15.2, 0.8]`

## Шаг 5: Вычисление сингулярных значений

**Формула:** `σᵢ = √λᵢ` (квадратный корень из собственного значения B)

**Код:** строки 391-392:
```kotlin
val sing = DoubleArray(r)
for (i in 0 until r) sing[i] = sqrt(max(0.0, lambdaSortedB[i]))
```

**Пример:** Если `lambdaSortedB = [250.5, 15.2, 0.8]`, то:
- `sing[0] = √250.5 ≈ 15.83`
- `sing[1] = √15.2 ≈ 3.90`
- `sing[2] = √0.8 ≈ 0.89`

**Важно:** `r = min(m, n) = min(5, 3) = 3`, поэтому у нас 3 сингулярных значения.

---

## Шаг 6: Построение матрицы V (правые сингулярные векторы)

**V** — это матрица собственных векторов B, упорядоченных по убыванию собственных значений.

**Структура:** V размером **n × n = 3 × 3**, где каждый **столбец** — это собственный вектор.

**Код:** строки 395-402:
```kotlin
val V = Array(n) { DoubleArray(n) }
for (col in 0 until n) {
    val vec = Vfull[idxB[col]]  // берём строку из Vfull
    for (i in 0 until n) V[i][col] = vec[i]  // кладём в столбец V
    gramSchmidtColumnInPlace(V, col)  // ортогонализация
    normalizeColumnInPlace(V, col)    // нормализация
}
```

**Важно:** 
- `Vfull` хранит векторы по **строкам**: `Vfull[vecIndex][i]`
- `V` хранит векторы по **столбцам**: `V[i][col]`
- Поэтому мы берём строку `Vfull[idxB[col]]` и кладём её в столбец `V[:, col]`

**Пример структуры V:**
```
V = [
  [v₀[0], v₁[0], v₂[0]],  // первый столбец = собственный вектор для λ₀
  [v₀[1], v₁[1], v₂[1]],  // второй столбец = собственный вектор для λ₁
  [v₀[2], v₁[2], v₂[2]]   // третий столбец = собственный вектор для λ₂
]
```

**Ортогонализация и нормализация:** После заполнения каждого столбца применяем процесс Грама-Шмидта и нормализацию для обеспечения ортонормальности: `V^T · V = I`.

## Шаг 7: Построение матрицы U (левые сингулярные векторы)

**Формула:** `uₖ = (1/σₖ) · A · vₖ`

где:
- `σₖ` — k-е сингулярное значение
- `vₖ` — k-й столбец матрицы V (правый сингулярный вектор)

**Код:** строки 405-414:
```kotlin
val U = Array(m) { DoubleArray(m) }
for (k in 0 until r) {
    val sigma = sing[k]
    if (sigma < 1e-12) continue
    val vk = DoubleArray(n) { i -> V[i][k] }  // k-й столбец V
    val Avk = multiplyMatVec(AArray, vk)      // A · vₖ
    for (i in 0 until m) U[i][k] = Avk[i] / sigma  // uₖ = (A · vₖ) / σₖ
    normalizeColumnInPlace(U, k)
}
```

**Пример для k=0:**
1. `v₀ = [V[0][0], V[1][0], V[2][0]]` (первый столбец V)
2. `Av₀ = A · v₀` (умножение матрицы A на вектор v₀)
3. `u₀ = Av₀ / σ₀` (деление на сингулярное значение)
4. Нормализация: `u₀ = u₀ / ||u₀||`

**Результат:** U размером **m × m = 5 × 5**, где первые `r = 3` столбца — левые сингулярные векторы.

**Дополнение до ортонормального базиса:** Если `m > r`, оставшиеся столбцы U дополняются до ортонормального базиса методом Грама-Шмидта (строки 417-423).

## Шаг 10: Проверка: A = U · S · Vt

**Формула реконструкции:** `A = Σₖ (σₖ · uₖ · vₖᵀ)`

где:
- `σₖ` — k-е сингулярное значение
- `uₖ` — k-й столбец U (левый сингулярный вектор)
- `vₖᵀ` — k-я строка Vt (правый сингулярный вектор)

**Код:** `reconstruct()` (строки 349-367):
```kotlin
for (k in 0 until r) {
    val sigma = S.data[k][k]
    if (abs(sigma) < 1e-12) continue
    for (i in 0 until m) {
        val uik = U.data[i][k]
        for (j in 0 until n) {
            Arec[i][j] += sigma * uik * Vt.data[k][j]
        }
    }
}
```

**Проверка:** Сравниваем `Arec` с исходной матрицей `A` с точностью `tolerance = 1e-4`.

## Итоговая структура SVD разложения

```
A (5×3) = U (5×5) · S (5×3) · Vt (3×3)
```

где:
- **U** — левые сингулярные векторы (ортогональная матрица, U^T · U = I)
- **S** — диагональная матрица сингулярных значений
- **Vt** — правые сингулярные векторы (ортогональная матрица, Vt · Vt^T = I)

**Свойства:**
1. `U^T · U = I` (ортогональность U)
2. `Vt · Vt^T = I` (ортогональность Vt)
3. `A = U · S · Vt` (точное разложение)
4. Все сингулярные значения неотрицательные и упорядочены по убыванию

## Математические формулы

### 1. Характеристический многочлен
```
p(λ) = det(B - λI) = λⁿ + pₙ₋₁·λⁿ⁻¹ + ... + p₁·λ + p₀
```

### 2. Собственные значения и векторы
```
B · vᵢ = λᵢ · vᵢ
```

### 3. Сингулярные значения
```
σᵢ = √λᵢ  (где λᵢ — собственное значение B = A^T · A)
```

### 4. Сингулярные векторы
```
A · vᵢ = σᵢ · uᵢ
uᵢ = (1/σᵢ) · A · vᵢ
```

### 5. SVD разложение
```
A = U · Σ · V^T = Σₖ (σₖ · uₖ · vₖᵀ)
```

где:
- `Σ` — диагональная матрица сингулярных значений
- `U` — матрица левых сингулярных векторов
- `V` — матрица правых сингулярных векторов

---

## Ключевые моменты реализации

1. **Метод Крылова:** Используется для построения характеристического многочлена без явного вычисления определителя.

2. **Поиск корней:** Бисекция + сканирование с адаптивным шагом для нахождения всех корней многочлена.

3. **Вычисление собственных векторов:** Формула Крылова позволяет найти собственные векторы без решения системы `(B - λI)v = 0`.

4. **Ортогонализация:** Процесс Грама-Шмидта обеспечивает ортонормальность векторов V и U.

5. **Сортировка:** Собственные значения и векторы сортируются по убыванию для соответствия стандартному виду SVD.
